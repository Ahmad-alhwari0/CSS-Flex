# CSS-Flex

A collection of Flexbox exercises covering core concepts: alignment, sizing, direction, wrapping, and building layouts using CSS Flexbox.

## Exercises
1. Boxes — basic flex row layout
2. Navbar — flexbox navigation bar
3. Flexible box sizing based on content
4. Equal-width flex items
5. Flex-wrap with multiple word tags
6. `align-self` — individual item alignment
7. `flex-direction` — column layout
8. Controlling flex item size with ratios
9. `flex-wrap` — grid-like layout (3 per row)

## Tech Stack
- HTML5
- CSS3 (Flexbox)

## Run
Open any exercise's `.html` file in a browser, or use VS Code's Live Server.
